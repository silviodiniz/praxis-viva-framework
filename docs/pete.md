# 🧠 Modelo Práxis Viva
 
 PETE — Protocolo de Exposição de Tensões Estruturais
________________________________________
🎯 FINALIDADE
O PETE é o instrumento oficial do Práxis Viva para:
•	registrar decisões sob tensão 
•	tornar visíveis conflitos estruturais do trabalho 
•	transformar situações críticas em dados de aprendizagem organizacional
